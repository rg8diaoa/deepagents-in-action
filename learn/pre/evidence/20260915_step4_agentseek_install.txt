术语注: 下文引用的原始报错串『TRAE Sandbox Error』保留沙箱原文未改——TRAE 即本仓约定所称的 Agent 沙箱。
命令: uv tool install --upgrade agentseek
结论: 安装成功（agentseek==0.1.4，93 个依赖包，Installed 1 executable: agentseek）；
